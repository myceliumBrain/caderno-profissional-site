📓 Caderno primeiro acesso

Cole um token de acesso pessoal do GitHub (fine-grained, restrito ao repositório , com permissão Contents: Read and write; crie em github.com/settings/personal-access-tokens/new) e escolha uma senha. O token e os seus textos ficam criptografados com essa senha.

🔑 Código de recuperação

Se você esquecer a senha, este código é a única forma de abrir o caderno. Anote no papel ou num gerenciador de senhas. Ele não será mostrado de novo.
